# operating-system-not-included

A small educational operating system project focused on embedded systems and low-level programming.

The project is being built step by step, covering concepts such as boot flow, memory initialization, exception handling, interrupts, and kernel development on ARM Cortex-M.

## Documentation

A complete example OS will soon be available in the documentation, with each part explained from the ground up.

The goal is to make it possible to follow the implementation while understanding what is happening at the hardware and kernel level.
